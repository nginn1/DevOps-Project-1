# DevOps-Project-1

## Run the Setup.sh file found inside the code folder.
## The script will then open the application. To proceed with the rest of the script you have close the application and then it will test the application, generate the .exe file, and then launch the website. From there you can visit the site at localhost:8080 in your browser and download the .exe file for yourself.
## I deployed the site using azure and deployed from my local machine through command line. The site has two pages. The download/home page and an about page that describes the application. Both of these are hosted by the azure web service.
